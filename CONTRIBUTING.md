# Contributing

Start with docs/BUILD.md and docs/ARCHITECTURE.md. Keep changes scoped and describe the concrete behavior and validation in pull requests.

For reports, include game/mod versions, reproduction steps, and relevant redacted log excerpts. Do not upload worlds, saves, account files, tokens or complete game directories.

High-priority work: native DirectX 12 depth-aware composition, camera/frame synchronization, proper wall collision, and authenticated official-launcher validation. Keep offline/version checks and upstream license notices intact.
